# MyGravityMap

Google マップのタイムライン履歴（`location-history.json`）から、
**自分がどこに引き寄せられて生きてきたか**を可視化するブラウザアプリ。

滞在時間と訪問回数から場所ごとの「重力」を計算し、地図上に重力井戸として描きます。

> **位置データはブラウザの外に出ません。** サーバへの送信もアップロードもありません。
> 解析はすべて端末内（Web Worker）で行い、結果は IndexedDB に保存されます。

**公開版**: https://mastermk2.github.io/MyGravityMap/
（[デモデータで開く](https://mastermk2.github.io/MyGravityMap/?demo) — 架空の人物の約 7 年分）

設計: [docs/DESIGN.md](docs/DESIGN.md) / 変更履歴: [CHANGELOG.md](CHANGELOG.md)

## できること

- **タイムライン再生** — 期間を選んで移動を早送り。移動痕は**グラデーション（彗星の尾）**か
  **実線（消えずに残る）**。速度は実時間倍率か「動き」基準、空白スキップ、コマ送り（← →）、
  ループ、カメラの追従／日ごとの自動フィット、滞在中の表示つき
- **重力マップ** — よく居た場所をヒートマップ／3D 六角柱で。重みは「居た日数」（既定。
  記録の濃さが年で違っても比べられる）・軌跡から推定した滞在時間・Google の訪問データから選べる
- **場所ランキング** — 選んだ期間の上位の場所（日数・時間・回数）。名前を付けると端末に保存。
  任意で OpenStreetMap から地名を取得（押したときだけ通信）
- **統計** — 移動距離（年ごと・飛行を分けて）、交通手段別、時間帯・曜日、新しく訪れた場所の数
- **カレンダー** — 日ごとの移動距離・記録時間・訪問数を年 × 日の格子で。日を押すとその日を再生
- **遠征** — 生活圏から離れた旅行・遠出を自動で抽出し、押すとその期間と範囲へ移動
- **重心の変遷** — 年ごとの生活の中心と行動半径（回転半径）を地図に重ねる
- **書き出し** — 地図の画像（PNG）、再生の動画（WebM / MP4）、場所・軌跡の GeoJSON
- **PWA** — 一度開けばオフラインでも起動できる（地図タイルは除く）

## 追加の表示・読み込み設定

- 重力マップの「年内正規化」で、その年の中での順位と生の値を切り替えられます。
  新規設定の既定は順位です。既存の保存設定は生の値を維持します。
  UTCの各年と選択期間の共通部分についてマスを集計し、正の値だけを順位化します。
  同値は平均順位（midrank CDF）、1マスだけなら0.5、0・負数・非有限値は0です。
  データのある年を同じ重みで平均し、記録がない年は平均から除外します。
  記録がある年に訪れなかったマスは0として扱います。値は滞在日数や秒数ではありません。
- 再生バーの表示設定に「補間方式」を追加しました。既定の線形と、点ごとに進む補間なしを選べます。
  飛行区間の取り込み時の大圏補間は維持されます。
  飛行の推定点数は分割閾値から独立し、1区間512点までです。飛行区間は粗い補間でも途切れません。
  解析全体の追加推定点が100,000点を超える場合は、部分結果を保存せず読み込みエラーを表示します。
- 読み込み画面の「トリップ分割閾値」は1〜1440分（既定30分）。変更後はJSONを再度選びます。
  閾値ごとに解析キャッシュを分け、元のJSONは変更しません。

## 対応データ形式

Google マップのタイムラインを端末からエクスポートした新形式の JSON。

```
{ "semanticSegments": [...], "rawSignals": [...], "userLocationProfile": {...} }
```

2024 年秋より前の期間には `visit`（訪問場所）が含まれないため、
本アプリは `timelinePath` から滞在を自前で復元して補完します（詳細は設計書 §1.2）。

また記録の濃さが年によって大きく異なる（2019 年は 1 日あたり約 6 時間分、
2025 年は約 15 時間分）ため、既定の重力スコアは滞在時間ではなく**居た日数**
（同じ日の再訪は 1 日）を使います。Google の訪問データによる滞在時間は 2024 年 10 月以降のみ有効です。

## タイムラインの取り出し方

タイムラインは端末内に保存されているため、端末から書き出します。
**Android と iPhone で場所が違います**（2026 年 8 月時点、[Google マップ ヘルプ](https://support.google.com/maps/answer/6258979?hl=ja) より）。

- **Android**: 端末の「設定」アプリ → 位置情報 → 位置情報サービス → タイムライン →
  タイムライン データをエクスポート
- **iPhone / iPad**: Google マップ → プロフィール写真 → 設定 → 個人的なコンテンツ →
  位置情報の設定 → タイムライン データをエクスポート → ファイルに保存

書き出されるファイルは `location-history.json`（JSON）で、記録が長いと数十 MB になります。

## 使い方

公開版を開いて、書き出した JSON を選ぶかドロップするだけです。手元で動かす場合:

1. `npm install && npm run dev`
2. ブラウザで書き出した JSON を選択（または「デモデータで試す」）

開発時は `Sampledata/` に JSON を置くと `?dev=/Sampledata/location-history.json` で
ファイル選択を飛ばせます（このフォルダは Git 管理外）。`?demo` はデモデータを直接開きます。

キーボード: Space 再生／一時停止、← → 1 日（Shift で 1 週間）、h パネルを畳む。

### 公開（GitHub Pages）

`main` に入ると `.github/workflows/deploy.yml` が typecheck・test・build を通してから
GitHub Pages に公開します（`BASE_PATH=/MyGravityMap/` でビルド）。

## データの取り扱い

- `Sampledata/` および位置データ由来のファイルは `.gitignore` 済みです。
- エクスポートには自宅・職場の座標や周辺 Wi-Fi の MAC アドレスが含まれます。
  リポジトリ・Issue・スクリーンショットに実データを含めないでください。
- `rawSignals`（MAC アドレスを含む）は取り込み時に破棄し、保持しません。
- 外部への通信は地図タイルの取得と、利用者が「地名を調べる」を押したときの
  OpenStreetMap Nominatim への座標の問い合わせ（1 秒に 1 件・結果は端末に保存）だけです。
- 端末に保存した解析結果・ラベル・設定は「概要」タブの「保存データをすべて消す」で削除できます。
